## Суть проекта

Это не шаблон, а полноценное портфолио, которое я спроектировал и реализовал с нуля: от UI‑кита в Figma до продакшн‑версии на GitHub Pages.  
Сделано: **полный цикл фронтенд‑разработки без фреймворков**.  
Измеряется в: **3 адаптивных состояния** (мобильное, планшет, десктоп 1440px) + **единая дизайн‑система** + **чистая архитектура кода**.  
Приносит пользу: **наглядно показывает уровень вёрстки, системный подход к проекту и умение работать по макету**.

---

## Ключевые достоинства

- **Pixel‑perfect вёрстка по макету** — все ключевые блоки (хедер, hero, «Обо мне», проекты, контакты, футер) реализованы точно, с соблюдением отступов, цветов и ритмов.  
  Польза: сразу видно, что умею переводить дизайн в код без искажений.
- **Единая дизайн‑система и цветовая палитра** — фиксированные цвета (включая акцентный «синий электрик»), типографика и ритм отступов реализованы через CSS‑переменные, консистентные отступы.  
  Польза: проект легко поддерживать и масштабировать, дизайн остаётся консистентным на всех страницах.
- **Умная адаптивность** — проект корректно отображается на реальных устройствах, включая узкие экраны вроде iPhone 11 Pro (375px). Использую `clamp()` для шрифтов и продуманные breakpoints.  
  Польза: интерфейс остаётся читаемым и удобным на любом устройстве — без «поехавшей» вёрстки.
- **Семантика и SEO** — структура построена на семантических тегах (`header`, `main`, `section`, `article`, `footer`), прописаны `title` и `meta`, URL‑структура понятна поисковикам, для соц. сетей добавлена Open Graph разметка.  
  Польза: проект не просто выглядит хорошо, но и технически грамотно сделан с точки зрения индексации.
- **Интеграция формы через Web3Forms** — реализована валидация и отправка данных без перезагрузки страницы. Форма протестирована: submissions видны в панели Web3Forms.  
  Польза: показывает навык работы с внешними сервисами, обработки пользовательского ввода и проверки результата.
- **Доступность и UX** — добавлены фокус‑стили (`focus-visible`) для навигации с клавиатуры, проработаны состояния `hover` и `active` для кнопок и ссылок (визуальная обратная связь при взаимодействии), используются SVG‑иконки вместо растровых.  
  Польза: интерфейс удобен и доступен для разных пользователей (в том числе при навигации клавиатурой), а чёткие визуальные состояния делают взаимодействие предсказуемым и приятным.
- **Продуманная архитектура кода** — БЭМ‑методология, логичная структура файлов, понятные имена классов, отсутствие лишнего.  
  Польза: любой разработчик может быстро разобраться в проекте и внести правки без лишних вопросов.
